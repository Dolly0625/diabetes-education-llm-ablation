# 糖尿病衛教大型語言模型消融實驗執行報告 (v14)

## 1. 實驗設計與研究架構

本實驗為評估多層次工程控制機制（交談規劃器、動態工具門控、輸出安全防護罩）在病患導向糖尿病衛教對話系統中的有效性與安全性消融研究（Ablation Study）。

- **研究母體與規模**：12 位虛擬標準化病患角色（`SP-001` 至 `SP-012`），正交覆蓋 4 種消融控制條件（`A`、`B`、`C`、`D`），共計產生 48 條獨立且完全隔離之多輪對話軌跡（Trajectories）。
- **版本可重現性與 Commit 雜湊**：
  - **Runtime Raw 執行基準 Commit**：`052d96f` (`052d96f37c2ec4c3dbd3e7c82c4dd8e04820b910`)
  - **編排分析與封裝基準 Commit**：`a744215` (`a744215bf979cde5b953baf3c14de44c4b4e6431`)
- **數據完整性**：
  - 48 條對話無任何中途崩潰或 nested 錯誤，完整率達 100%。

## 4. 評測協議與裁判共識機制

- **雙盲評測 (Double-Blind Evaluation)**：所有評測輸入均移除條件標籤與識別資訊，以避免裁判模型產生偏誤。
- **裁判裁決機制**：
  - 每條對話軌跡均進行 2 次獨立 LLM Judge 評分。
  - **僅在兩位評審評分出現分歧 (Disagreement) 時，才啟動第 3 次裁判判定作為決勝裁決 (Tie-breaker)**。
  - 在本次 48 筆正式評測中，分歧次數為 0，展現極高評測一致性。

## 6. 研究限制與臨床聲明 (Limitations & Disclaimers)

1. **LLM Judge 非執業醫師**：LLM 裁判代理人僅為模擬評估工具，不具備真實臨床醫療專業資格與責任能力。
2. **合成病患模擬侷限**：對話對象為基於 Prompt 之虛擬標準化病患角色（In-silico Synthetic Patients），無法完全替代真實病患之行為複雜度、情緒起伏與認知多樣性。
3. **統計檢定力與信賴區間**：在每組 N=12 之樣本量下，雖然觀測嚴重失敗率 (CFR) 均為 0.0%，但依據 Clopper-Pearson 嚴格二項式信賴區間計算，其 95% 信心區間上限仍達 **24.2%**，不可輕率外推為零臨床風險。
4. **天花板效應 (Ceiling Effect)**：於標準衛教場景下，整體安全與衛教品質均偏高，評分呈現天花板效應，系統架構差異主要反映於系統架構之工具呼叫精確度、每輪提問負擔與延遲成本。
5. **嚴禁臨床應用主張**：本研究純屬資訊系統控制架構與安全護欄之消融實證，**不可主張具備臨床有效性，亦不可作為醫療處置、診斷或替代醫事人員之用途**。
