\## 2. 最終選用參數與理由



\- \*\*RRF\_K\*\*: 10

\- \*\*W\_GRAPH / W\_VECTOR\*\*: 1.5 / 1.3 (權重比 1.15:1)

\- \*\*DEFAULT\_TOP\_N\*\*: 6

\- \*\*選用理由\*\*: 

&#x20; 1. \*\*修正排序平滑問題 (`RRF\_K = 10`)\*\*：將 `RRF\_K` 從預設 60 調降至 10，解決原先分母過大導致兩軌名次得分差距被壓平的問題，放大前排優質候選的得分鑑別度。

&#x20; 2. \*\*兼顧安全與增強向量 (`W\_GRAPH = 1.5`, `W\_VECTOR = 1.3`)\*\*：維持圖譜 1.5 的高強度安全基礎，改透過主動調升向量權重至 1.3，縮小兩軌分數落差，讓優質衛教段落具備競爭力。

&#x20; 3. \*\*解除輸出容量瓶頸 (`DEFAULT\_TOP\_N = 6`)\*\*：原先 Top N = 5 的限制下，前 5 個位置全被優先權較高的 Graph 軌道佔滿，導致排名第 6 的正確 Vector 衛教段落被硬性截斷。放寬至 Top N = 6 剛好提供額外 1 個關鍵容量，成功使 Vector Recall 從 0.40 提升至 0.45；同時避免了放寬至 Top N = 7 時導致 Precision 過低、整體 F1 大幅下滑（降至 0.27）的雜訊問題。



\## 3. 安全性與權衡效應 (Trade-off) 說明



實驗 3 與 4 顯示，若單純透過調低 `W\_GRAPH`（至 1.15 以下）來給向量讓路，會導致 Graph Recall 降至 0.85，將關鍵的結構化禁忌事實擠出前排，嚴重違反醫療安全規範（`CONTRACT\_v1.md`）。因此，最終採用「維持圖譜高權重 + 主動增強向量權重 + 微放寬 Top N 至 6」的組合，在完全符合 $W\_{GRAPH} > W\_{VECTOR}$ 安全約束的前提下，達到 Graph Recall ≥ 0.95 且 Vector Recall 提升至 0.45 的最佳平衡。
