# RAG 觸發政策（v3 護理師什麼時候查書：分享不查、提問必查）

> 生效：2026-09-09｜原則：**閒聊靠嘴，飲食提問與定義跟藥靠書，救命靠反射**｜九成閒聊不查書，提問必查書。

| 情境（阿嬤問什麼） | 查不查 | 去哪查 | 備註 |
|---|---|---|---|
| 今天吃什麼、麵線糊好吃嗎（純分享/閒聊） | 不查 | 護理師常識＋追份量 | 查了反而撈出藥名雜訊（類澱粉案，現已由內部過濾器解決），純分享飲食同理關懷即可，無須查書 |
| 飲食知識與風險提問（要注意什麼、會不會升血糖、能不能吃、可以吃多少） | 查（強制先查） | 向量軌手冊飲食章加營養成分表，圖譜軌照丟由現有過濾器把關 | 2026-09-09 升級 v3 新增；官方背書，以手冊飲食原則與水果份量衛教 |
| 睡眠、腳痠、心情等陪聊 | 不查 | 常識同理 | 查書無意義 |
| 糖尿病定義、成因、形成機制 | 查（強制先查，程式執行不問模型） | 國健署手冊第一章＋向量軌；圖譜軌丟棄（`TREATS` 對定義永遠是雜訊） | 2026-09-06 新增；答錯代價大，手冊背書 |
| 藥物安全（副作用、傷腎、脹正不正常、交互作用、藥袋辨識） | 查（強制先查） | TFDA 仿單＋圖譜 | 只解釋、不給調藥指示；出處只印就醫備忘錄不念 |
| 官方數字標準（空腹標準、HbA1c 目標） | 查（強制先查） | 手冊＋仿單 | 數字題官方說了算 |
| 低血糖當下（65 暈了怎麼辦） | 不查，先處置 | 15 克糖反射話術 | 救命優先，書以後再翻 |
| 整理就醫備忘錄／看診備忘 | 不查 | 前面記下的格子直接印 | 用記憶，不再撈 |

## 強制先查的含義

- planner 判出 `GENERAL_EDUCATION`（定義）、`DRUG_SAFETY`（藥物安全）或 `DIET_NUTRITION_KNOWLEDGE`（飲食提問）時，由程式直接調 `search_handbook`（query 規則改寫），證據先備好再叫護理師翻白話。模型無權跳過。
- 出處（`evidence_links`）只印在就醫備忘錄小字，不進聊天正文（出處只印不念，避免長輩拿半調子知識挑戰醫師）。
- 自述歸阿嬤、出處歸書；沒查就空著，絕不編造頁碼。

## 不查的保證

- `DIET_NUTRITION`（純分享型飲食）領域物理隱藏 `search_handbook`（`state.py`），模型想叫也叫不到。
- RAG 掛掉／查無時降級：飲食回 HPA 五點大原則，其他回「手冊暫未查得，回診問醫師」，絕不現編。
